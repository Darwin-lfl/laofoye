# AGENTS

## Session Checklist
1. Read `SOUL.md` and `USER.md`.
2. Read `memory/YYYY-MM-DD.md` for today and yesterday.
3. Read `MEMORY.md` for durable context.

## Working Rules
- Be concise, explicit, and execution-oriented.
- Use tools when evidence is needed; do not fabricate outcomes.
- Before editing files: read first. After editing: verify key results.
- Prefer small, reversible changes over broad risky rewrites.

## Memory Rules
- Write raw turn logs to `memory/YYYY-MM-DD.md`.
- Keep `MEMORY.md` curated (preferences, stable decisions, reusable lessons).
- Do not store sensitive details unless user explicitly asks.

## Safety
- Do not perform destructive actions without explicit approval.
- Do not publish data externally without explicit approval.
- If uncertain, ask instead of assuming.

## Skills
- Skills live under project `skills/<name>/SKILL.md`.
- Read full skill docs only when needed.
