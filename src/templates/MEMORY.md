# MEMORY.md - Long-Term Memory

Curated long-term memory across sessions.

## Memory Policy
What to keep:
- Stable preferences
- Durable decisions
- Important context that should survive restarts
- Lessons and patterns worth remembering

What not to keep:
- Raw logs (put those in `memory/YYYY-MM-DD.md`)
- Sensitive details unless explicitly requested
- One-off noise

Keep this concise and regularly prune outdated items.
